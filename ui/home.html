YOUR ROUTINE

안내 일정·이용 방법

01

매일 오전 9시, 목록 확인

공개 공고와 응모 조건을 대조한 간단 응모·정답형 퀴즈를 안내합니다. 정답에는 답안 내용과 근거를 함께 표시합니다.

02

안내 후 약 30분, 상태 선택

페이지를 열어 두면 선택 안내창이 표시됩니다. 채팅 후속 확인은 5분 간격 검사로 약 30~35분 뒤 요청합니다.

03

선택 기록은 다음 날 반영

참여했음·참여 의사 없음은 다음 한국 날짜부터 같은 행사를 제외합니다. 나중에 참여·미선택은 남겨 두며 새 회차는 별도입니다.

04

이 컴퓨터에서 사용하는 홈페이지

HTML·CSS·자바스크립트 화면과 로컬 서버로 작동합니다. 정기 조사는 Codex 예약이 담당하며 PC·앱·서버가 켜져 있어야 합니다. 외부 공개 사이트는 아닙니다.

실제 이름·전화번호·계정 정보는 입력하지 않습니다. 선택 기록은 사용자가 알려준 참여 상태이며 행사 접수 증거가 아닙니다. Windows 알림 배너 안의 직접 선택 기능과 실제 푸시 수신은 확인되지 않았습니다.
