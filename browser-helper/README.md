# 모아봄 Npay 탭 닫기 보조 확장

## 최신 동작 (0.2.0)

열기 기준 타이머를 폐기했다. 모아봄이 연 campaign2.naver.com/npay/v2/click-point/ 탭에서 사용자가 ‘포인트 받기’를 실제 클릭한 시점부터5초 뒤 닫는다. 버튼은 자동 클릭하지 않는다. 창을 활성화·스크롤·시청하거나 체류시간 충족을 판단하지 않는다. 클릭 전에는 무기한 기다리며, 수동으로 닫으면 대기 기록만 지운다. 다른 광고사 Adison은 감지 권한을 추가하지 않았으므로 수동 닫기·완료다.

해당 페이지에 content script를 실행하는 권한과 storage 권한이 추가된다. Chrome의 권한 경고는 사이트 단위의 ‘데이터 읽기 및 변경’으로 표시될 수 있으나 코드는 위 경로의 버튼 클릭만 관찰하고, 실제 확장이 만든 탭만 처리한다. 계정·쿠키·토큰·잔액·입력값은 읽지 않는다. storage.session에는 탭 ID·홈페이지 ID·선택키·무작위 시도ID·시작 여부만 저장하며 탭을 닫으면 지운다. 서비스워커가 잠들어도 대기를 유지하기 위한 임시 저장이다. 브라우저 재시작 뒤에는 복원하지 않는다.

권한 적용은 사용자의 명시 승인 후 확장 카드 새로고침/사이트 접근 허용으로 수행한다. 새 가상 시험도 ‘가상 포인트 받기’를 누르기 전에는 닫히지 않는다. 시험 탭은 참여완료에 저장하지 않는다. 아래0.1.0 검증 기록은 열기 기준의 과거 결과이므로0.2.0 동작의 증거로 재사용하지 않는다.

2026-10-16 설치·검증 완료: 사용자가 Chrome 설치와 확장 새로고침을 직접 수행했다. Chrome 홈페이지 연결 확인, COOP same-origin 로컬 시험 탭이 실제 탭 목록에서 사라지는 것을 도구로 확인했고, 실제 적립 링크도 약5초 뒤 닫힌다는 사용자 확인을 받았다. Codex 내장 브라우저에 설치된 것은 아니다.

현재 Codex 내장 브라우저의 설치 가능한 확장 지원은 확인되지 않았다. 이 패키지는 Chrome 확장이다. 설치 승인 및 최초 실제 닫기 검증은 위 기록을 따른다. 이후 파일 변경 시 Chrome 확장 카드와 홈페이지를 새로고침해야 한다.

## 동작과 범위

Chrome에서 http://127.0.0.1:4179/ 홈페이지의 실제 사용자 왼쪽 클릭만 받는다. 허용된 두 적립 URL 형식만 새 탭으로 만들고 그 생성 ID를5초 뒤 chrome.tabs.remove에 전달한다. 외부 리디렉션으로 페이지의 WindowProxy 참조가 끊겨도 브라우저 탭 ID를 사용한다. 수동으로 먼저 닫으면 그대로 종료한다. 기존 탭·다른 사용자 탭을 검색하거나 닫지 않는다.

최신 사용자 승인: 닫기 성공 후 원래 홈페이지의 content script로 광고 selectionKey·무작위 attemptId를 알리고, 같은 출처의 /api/npay/complete에 저장한다. source=user-authorized-tab-close로 완료 목록에 보관하지만 지급/응모 증거는 null이다. 홈페이지를 열어 둬야 알림을 받아 로컬 저장할 수 있다. 열기/닫기 실패·시험 탭은 보관하지 않는다. 홈페이지가 닫혔거나 저장이 실패한 경우 성공을 추정하지 않으며, 화면에 저장 실패가 보이면 수동 참여완료 버튼을 사용한다. 지급 여부는 사용자가 확인한다.

manifest에 tabs·cookies·history·scripting·외부 광고 호스트 권한을 선언하지 않았다. Chrome content-script 매치 패턴의 포트 한계 때문에 127.0.0.1에 선언하되 코드에서4179·루트 경로·최상위 프레임으로 제한한다. 광고 내용을 읽거나 쿠키/토큰을 수집하지 않는다. 보안 헤더를 제거하거나 CDP 권한을 넓히지 않는다. 코드/포인트 지급/자동 응모 스케줄은 실행하지 않는다.

## 승인 후 설치·실제 시험 절차

1. 사용자가 Chrome에서 chrome://extensions를 열고 개발자 모드 활성화·압축해제 확장 로드를 직접 수행한다. 선택 폴더는 이 README가 있는 browser-helper 폴더다.
2. Chrome에서 http://127.0.0.1:4179/#npay를 새로 열거나 새로고침한다. 내장 브라우저의 탭과 혼동하지 않는다.
3. 사용자가 적립 링크를 직접 누른다. 생성 탭만 약5초 뒤 닫히는지 실제 탭 목록으로 검증한다. 설치 성공·페이지 참조의 closed:true만으로 통과하지 않는다.
4. 실제 금융·개인정보·동의·가입 단계는 진행하지 않는다. 점유시간·추가 미션이 필요한 광고에서는5초 닫기가 적립을 보장하지 않는다.

자동 시험은 worker의 URL/출처 제한·새 탭 ID만 닫기·같은 창 지정·5000ms 예약을 모의 Chrome API로 검증한다. 도구의 실제 Chrome 검증과 사용자의 실제 적립 링크 확인은 verification/npay-close-fix-20261016/REPORT.md에서 구분한다.

0.2.1: ‘클릭 적립은 캠페인 당 1회만 적립됩니다’ 안내의 확인 버튼을 사용자가 직접 누른 경우에도5초 뒤 닫는다. 일반 확인 버튼은 감지하지 않으며 자동 클릭하지 않는다. 기참여 안내로 보관된 항목은 적립일 미확인으로 구분하고 신규 기간 통계에서 제외한다. 기존 권한 범위 유지.
